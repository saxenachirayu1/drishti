# Fonts

Bundled so the app renders the same offline and in tests. All are under the SIL Open Font License 1.1 (each family's licence is next to it), from Google Fonts via the @expo-google-fonts npm packages.

- Source Serif 4 SemiBold: headings
- Public Sans: body text
- IBM Plex Mono: ticket codes, dates, measurements
- Tiro Devanagari Hindi: Hindi headings
- Noto Sans Devanagari: Hindi body text
