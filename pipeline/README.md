# pipeline/ (Member B)

- `drishti_pipeline/` Python package: imagery search, preprocessing, tiling, inference, polygons, site tracking, FIRMS, fire risk
- `training/` TerraTorch configs and checkpoints info for fine-tuning Prithvi
- `labels/` dumpsite polygons (GeoJSON) and the labelling guide
- `notebooks/` exploration and training notebooks (Colab)
- `tests/` unit tests

Model weights and raw imagery are not committed (see `.gitignore`).
